# 开源准备清单

目标：源码、文档和样例可以公开审查，同时不把本机试用包、真实账户材料或未完成的
生产门当成正式发行。以下“未完成”项不得用离线演示替代。

## 必须由项目负责人决定

| 项 | 当前状态 | 完成条件 |
| --- | --- | --- |
| 许可证 | **MIT**（[LICENSE](../LICENSE)） | 已由项目负责人选择；公开前复核贡献者/第三方资产条款 |
| 公开范围 | 未授权 | 审核源码、历史、样例、截图、依赖和 Release 资产；剔除凭据、用户路径、任务数据 |
| 品牌/命名 | 未核查 | 在 GitHub、搜索引擎和分发渠道查重；必要时加副标题或改名 |
| 安全联系渠道 | 本文给出临时方式 | 指定维护者邮箱/私密渠道并在 GitHub Security 中启用 |
| 正式签名发行 | 不适用 | 项目没有 Apple 开发者账号；只发布未签名 DMG 开发预览，首次启动需手动放行 |
